# My Anime Tracker

A simple app for anime viewers to track shows they are watching,
have completed, or plan to watch.

## Features

- Add anime with a title, status, and rating
- Edit anime details
- Delete anime
- Save the list in the browser
- Mobile-responsive layout

## Technologies

- HTML
- CSS
- JavaScript

## How to Use

Open index.html in a browser.
Fill in the form and click Add Anime.
Use Edit to change an entry or Delete to remove it.
